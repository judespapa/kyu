# kyu

Home for personal Agent SDK projects.

## email-inbox

Gmail inbox manager: triage unread mail, draft replies, and organize
labels. Lives in [`email-inbox/`](./email-inbox/).

### Local

```bash
cd email-inbox
npx @grok/agent-sdk@0.6.0 login
npx @grok/agent-sdk@0.6.0 dev
```

Connect the Cursor **Gmail** plugin (or connect Gmail under Deployed
Agents MCP) before asking it to read your inbox.
